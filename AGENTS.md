## Проект

Кейс HackAlem AI «Граф денег»: по графу внутрибанковских переводов (2 248 узлов, 3 119 рёбер,
4 840 транзакций за июль 2026) определить роль каждого участника финансовой сети, разбить сеть
на кластеры и ранжировать узлы по приоритету проверки для AML-аналитика.

Полное ТЗ — `CASE-TZ.md`. Разбор и чеклист — `CASE.md`.
Архитектура — `ARCHITECTURE.md`; уточнения и варианты — `DECISIONS.md`.
Документы находятся в корне. Порядок реализации — `PLAN.md` и `CODEX-TASKS.md`.

## Стек

Python 3.11+ · pandas · pyarrow · networkx · numpy · Streamlit · pyvis
OpenAI API — только в опциональном слое `src/ai/`.

## Карта репозитория

```
run.py              единственная точка входа пайплайна
src/load.py         загрузка parquet и sanity-check
src/graph.py        сборка направленного взвешенного графа
src/features.py     метрики узла
src/temporal.py     временные признаки из transactions.parquet
src/roles.py        правила ролей и пороги — сердце решения
src/clusters.py     Louvain и сводка по кластерам
src/priority.py     priority_score и топ-лист
src/gaps.py         оценка полноты: что дозапросить
src/narrate.py      шаблонные evidence / why / hypothesis, работает офлайн
src/ai/             опциональный слой агентов, включается флагом --llm
src/export.py       запись трёх CSV в схеме ТЗ
app.py              Streamlit: граф, поиск по gid, карточка узла, топ-лист
config.yaml         все пороги и веса
data/               parquet от организаторов
out/                nodes_roles.csv, clusters.csv, top_nodes.csv
```

## Команды

```bash
pip install -r requirements.txt
python run.py --data data --out out      # полный пересчёт, обязан укладываться в 5 минут
python run.py --data data --out out --llm  # то же + слой агентов, требует OPENAI_API_KEY
streamlit run app.py                      # экран просмотра
```

Деплоя нет — всё работает локально, проект живёт в git.

## Правила

1. **Пайплайн обязан работать без ключа OpenAI.** Жюри запускает `python run.py` на чистой
   машине и должно получить все три CSV. Любой вызов модели — только под флагом `--llm`
   и только как улучшение уже готового текста. Отсутствие ключа не ломает и не замедляет прогон.
2. **Роль присваивает код, а не модель.** Роли, скоры, кластеры и приоритеты считаются
   детерминированными правилами из `config.yaml`. ТЗ запрещает «чёрный ящик»: роль без
   объяснимого правила не засчитывается.
3. **Никакого хардкода результата.** Списки конкретных gid в коде запрещены прямым пунктом ТЗ.
   Всё выводится из расчёта.
4. **Не выдумывать атрибуты клиентов.** В данных нет ни ФИО, ни возраста, ни типа операции,
   ни остатков. Любое такое поле считается выдумкой и снимает баллы.
5. **Все пороги — в `config.yaml`.** В коде не должно быть числовых констант вроде `> 8`
   или `0.8`. Каждый порог сопровождается комментарием, почему он такой.
6. **Осторожность формулировок.** Любой текст, который увидит аналитик (`evidence`, `why`,
   `hypothesis`), формулируется как гипотеза для проверки: «признаки консолидации»,
   «требует проверки». Утверждения о виновности, «отмывает», «преступник» — запрещены.
   Это требование ТЗ, а не стилистика.
7. **Учитывать ловушки данных.** Узел с `depth == 4` и `out_deg == 0` — артефакт обхода,
   а не конечный получатель (таких 444). У seed занижены входящие, поэтому `pass_through`
   для них недостоверен. Граф направленный и взвешенный: ненаправленные методы — только
   с явной оговоркой.
8. **Схема выгрузок фиксирована.** Обязательные колонки удалять нельзя, добавлять свои можно.
   `nodes_roles.csv` — ровно 2 248 строк, включая узлы без единого ребра.
9. **Производительность.** Полный пересчёт ≤ 5 минут на обычном ноутбуке. `simple_cycles`
   только с `length_bound`. Тяжёлые метрики — с возможностью сэмплирования.
10. **Ключ OpenAI — из переменной окружения.** `.env` в `.gitignore`, ключ в коде и в логах
    не появляется.

## Стиль

- Функции чистые, с типами. Каждый модуль отвечает за один шаг пайплайна.
- Комментарии объясняют «почему такой порог», а не «что делает строка».
- Никаких заглушек и выдуманных чисел: если метрика не считается — сказать об этом,
  а не подставить правдоподобное значение.
- Русский язык в интерфейсе, в `evidence` и в README; английский в коде и коммитах.
