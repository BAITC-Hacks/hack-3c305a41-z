участника сети, разбивает сеть на кластеры и отвечает на вопрос «кого из 2 248 клиентов

## Запуск

```bash
pip install -r requirements.txt
python run.py --data data --out out
```

Одна команда, от сырых `.parquet` до трёх выгрузок. Ключ OpenAI **не требуется**.
Время полного прогона: [[ЗАПОЛНИТЬ: N]] секунд при лимите ТЗ в 5 минут.

Экран просмотра:
```bash
streamlit run app.py
```

Опционально — слой агентов, требует `OPENAI_API_KEY`:
```bash
python run.py --data data --out out --llm
```

## Ограничения подхода

Учтены ограничения данных, объявленные в ТЗ:

- **Обрыв на 4-м колене.** 444 узла имеют `depth=4` и ноль исходящих. Это артефакт обхода,
  а не «деньги осели», поэтому `terminal` им не присваивается; узлы помечены
  `data_limitation = truncated_at_hop_4`, уверенность снижена, по ним сформирован дозапрос.
- **Заниженные входящие у seed.** Граф собран от них по исходящим, поэтому `pass_through`
  для seed недостоверен и в определении их роли не используется.
- **Порог 5 000 KZT.** Дробление сумм ниже порога в данных не видно.
- **Неориентированная проекция для кластеризации.** Louvain работает на проекции без
  направления — это осознанный компромисс для задачи «кто с кем связан»,
  направление учитывается в ролях и приоритете.
- **Нет ground truth.** Оценить точность ролей не на чем; критерии обоснованы правилами,
  а не измеренной accuracy.
