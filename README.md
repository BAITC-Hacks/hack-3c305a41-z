# Граф денег

Проект для кейса HackAlem AI: роли участников транзакционной сети, кластеры и
объяснимый приоритет проверки для аналитика. Выводы — гипотезы, требующие проверки.

## Текущее состояние

На 23 сентября 2026 года в репозитории есть требования и проектные документы.
Код пайплайна, интерфейс, зависимости и данные пока отсутствуют.

Рекомендуемый объём: полный офлайн-MVP, затем временные признаки и проверка устойчивости
выводов. Варианты и обоснование — [DECISIONS.md](DECISIONS.md).

## Что нужно для первого прогона

- data/nodes.parquet, data/edges.parquet, data/transactions.parquet от организаторов;
- README датасета для проверки типов, дат и особенностей выгрузки;
- starter/starter.py, если доступен. Его отсутствие не блокирует реализацию по ТЗ.

До появления данных можно реализовать и проверить логику на явно синтетических графах.
Такие проверки не подтверждают результат на 2 248 узлах.

## Планируемый запуск после реализации

Сейчас эти команды выполнить нельзя: соответствующие файлы ещё не созданы.

```powershell
python -m pip install -r requirements.txt
python run.py --data data --out out
python -m streamlit run app.py
```

Установка зависимостей — подготовка окружения. Одна команда python run.py должна
выполнять весь расчёт без API-ключа и ручных шагов. Лимит ТЗ — 5 минут;
фактическое время пока не измерено.

## Планируемый результат

| Артефакт | Критерий |
|---|---|
| out/nodes_roles.csv | Строка на каждый входной gid, включая изолированные; на датасете ТЗ — 2 248 |
| out/clusters.csv | Размер, seed, внутренний оборот, ключевые узлы и гипотеза каждого кластера |
| out/top_nodes.csv | Не менее 20 узлов на датасете ТЗ, приоритет и числовое обоснование |
| Экран просмотра | Поиск любого входного gid, направленные связи, роли и кластеры |

Схемы обязательных колонок — раздел 5 [ТЗ](CASE-TZ.md). Окончательные пороги,
измерения и скриншоты появятся после реализации. role_score планируется как балл
соответствия правилу в диапазоне 0–1; без размеченных ролей это не измеренная вероятность.
